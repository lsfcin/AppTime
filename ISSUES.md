## B1 — the overall timer and every statistic count apps nobody monitors

**Symptom:** an app switched off in the per-app list still adds its time to the general timer and to
every analytics window. Lucas, INBOX 2026-08-27: Google Maps inflates his daily usage while sitting
in the unmonitored list, which reads as a bigger phone habit than he has.

**Why it matters:** the whole app is an awareness instrument. A number that counts what the user
explicitly excluded is not a partial answer, it is a misleading one — and the excluded apps are
exactly the ones with an innocent reason to run long (navigation, music, calls).

**Where to look:** `disabledApps` already decides overlay visibility; the same list has to gate the
aggregates. `analytics_service.dart` computes from raw SharedPreferences data and
`screens/analytics/analytics_helpers.dart` is shared by all three tabs, so the filter belongs at that
boundary rather than in each tab. Decide once and state it: does an unmonitored app disappear from
history retroactively, or only from the day it was switched off?
